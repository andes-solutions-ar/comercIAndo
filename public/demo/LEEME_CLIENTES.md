# comercIAndo · DEMO comercial restringida

Para visitar la demo, abrí `index.html` de esta carpeta; o publicá esta carpeta completa bajo HTTPS.

La demo permite visualizar la plataforma y consultar productos. No habilita altas/bajas de productos, cambios de stock, registro de ventas ni cobros, ni pedidos efectivos. El escáner móvil por QR también funciona en **modo consulta** y **no añade unidades al carrito**.

Para vincular un teléfono hay que publicar la carpeta bajo HTTPS, tener Internet y aceptar la solicitud desde la PC. No es posible vincular un teléfono usando archivos locales abiertos con doble clic.

**Aviso:** esta es una maqueta de frontend, no un sistema protegido por un backend. No utilizar como plataforma de producción ni introducir datos personales reales.
