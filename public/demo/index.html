Una demo para explorar, no para operar un comercio real

Los datos, clientes, precios y comprobantes son ficticios. Las operaciones de uso real están bloqueadas y las preferencias de demostración pueden reiniciarse. Esta muestra no procesa pagos, no emite facturas fiscales y no envía pedidos reales. El panel y la tienda funcionan de forma independiente; todavía no comparten una base de datos en tiempo real. No ingreses información personal real.
